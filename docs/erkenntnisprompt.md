# Stellt uns Fragen! / Ask us questions!

**Öffentlicher Erkenntnisprompt · Arbeitsfassung 1.0 · 05.11.2026**

Die Einladung gilt einfachen Verständnisfragen ebenso wie begründeten Einwänden gegen das gesamte Regelwerk. Die Antwort soll erklären, begründen, Unsicherheit benennen und Korrektur ermöglichen. Fehlendes Wissen bleibt als solches sichtbar. Ein Anspruch auf eine bestimmte Antwortzeit oder eine fachlich geprüfte Antwort entsteht durch eine Einreichung nicht.

## Anspruch und Grenze

Der Prompt soll Quellenprüfung, Unterscheidung von Aussagearten, starke Gegenargumente, explizite Wertannahmen und sichtbare Revision unterstützen. Er muss auch gegen sich selbst anwendbar bleiben. Er ist kein Wahrheitszertifikat, keine neue Modellfähigkeit und kein Nachweis für die Richtigkeit des Projekts. Seine Wirksamkeit ist **nicht systematisch evaluiert**.

Für eine spätere Evaluation: Aufgaben und Bewertungskriterien vorher festlegen; dasselbe Modell unter vergleichbaren Bedingungen wiederholt mit und ohne Prompt prüfen; Quellenfehler, unberechtigte Zustimmung, Umgang mit Unsicherheit, Nützlichkeit und unnötige Länge erfassen. Nach Möglichkeit unabhängig und verblindet bewerten. Gute Einzelbeispiele oder mehrere zustimmende KI-Rollen sind keine unabhängige Validierung.

Fehlerberichte nennen Promptversion, Modell, Datum, konkrete Frage, relevanten Antwortausschnitt, Fehler und Korrekturvorschlag. Private Angaben werden vor einer öffentlichen Einreichung entfernt. Änderungen am öffentlichen Prompt laufen über nachvollziehbare redaktionelle Prüfung; die bestehenden Schwarm-Workflows erhalten keine zusätzlichen Schreib- oder Veröffentlichungsrechte.

## English

The invitation welcomes beginner questions and substantive challenges to the framework itself. Answers should explain, substantiate, disclose uncertainty and remain revisable. Public GitHub submissions require an account and should contain no private information; no response time is promised.

Copy the rule pack into a chat and add your question, or attach the file if your AI accepts documents. It contains the nine foundational theses, the method and the complete inquiry prompt. From the worksheet you can also download the rules with your own notes. Review those notes before sharing them with your AI provider. A local assistant or script can read the English TXT link above as UTF-8 and pass the text as context. Fetch it again to update a saved copy. Builds on GitHub include source links for the exact commit.

The prompt's effectiveness has **not been systematically evaluated**. Future evaluation should compare repeated runs with and without the prompt under comparable conditions, using predefined criteria and preferably independent, blinded assessment. Failure reports should identify the prompt version, model, date, exact question, relevant excerpt, error and proposed correction. Existing editorial and licensing rules apply.
