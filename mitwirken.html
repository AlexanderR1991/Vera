01 / BEOBACHTEN

Eine konkrete Stelle nennen.

Zitiere eine These oder Seite und benenne präzise, welcher Gedanke falsch, unklar oder unvollständig erscheint.

02 / BELEGEN

Alternativen zeigen.

Bringe Quellen, mögliche Gegenbeispiele und alternative Erklärungen ein. Auch eine sauber formulierte offene Frage hilft.

03 / VERBESSERN

Eine Korrektur vorschlagen.

Zeige, wie die Aussage präziser, prüfbarer oder menschlich verantwortlicher werden könnte.

Einwände sind Beiträge.

Öffne ein GitHub Issue, um Kritik nachvollziehbar zu dokumentieren. Größere Textänderungen lassen sich als Pull Request einreichen. Für die Zusammenarbeit gelten unsere Beitrags- und Diskussionsregeln.
