# Grundtext des Wirklichen

> Die Wirklichkeit steht über diesem Werk.

**Arbeitsfassung 0.1** – eine offene Untersuchung von Wahrheit, Verantwortung, Würde, Freiheit und persönlicher Entwicklung.

[Website](https://AlexanderR1991.github.io/grundtext-des-wirklichen/) · [Grundtext](docs/grundtext.md) · [Methode](docs/methode.md) · [Mitwirken](CONTRIBUTING.md)

## Worum es geht
Ein korrigierbarer philosophischer Denkversuch, kein dogmatisches Bekenntnis, keine wissenschaftlich bewiesene Gesamttheorie und keine behauptete Peer-Review-Institution. Aussagen werden als Wissen, Hypothesen, Metaphern oder Praxisvorschläge unterschieden.

## Website
Statische HTML/CSS-Seiten ohne externe Skripte, Abhängigkeiten, Analysewerkzeuge oder Cookies. Lokal `index.html` öffnen. GitHub Pages: **Settings → Pages → Build and deployment → Source: GitHub Actions**. Der Workflow `.github/workflows/pages.yml` veröffentlicht nach Änderungen an `main`, sobald Pages aktiviert ist.

## Mitwirken
Kritik ist willkommen. Bitte [CONTRIBUTING.md](CONTRIBUTING.md) und [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) lesen. Änderungen nachvollziehbar und begründet einreichen.

## Vor der breiten Veröffentlichung klären
- Autorenschaft, Moderation und Kontaktmöglichkeit
- Offene Lizenz für Text und Code (derzeit keine Lizenz erteilt)
- Inhaltliche Freigabe und quellenbasierte Prüfung
- [Redaktionelle Grenzen](docs/redaktionelle-grenzen.md), insbesondere den Schutz privater Inhalte

## Transparenz
Entstanden auf menschliche Initiative im Dialog mit einem KI-Sprachmodell. Die menschlichen Verantwortlichen prüfen die Inhalte und entscheiden über Veröffentlichungen. KI-Aussagen sind keine unabhängigen Wahrheitsbelege.
